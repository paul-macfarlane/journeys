-- Hand-written below this line: a version published before these columns
-- existed showed the Journey's title and description as they were, and the
-- closest record of that is the Journey row today. Drizzle snapshots do not
-- track data, so this statement lives only here.
UPDATE "published_version" v
SET "title" = j."title", "description" = j."description"
FROM "journey" j
WHERE j."id" = v."journey_id" AND v."title" = '' AND v."description" = '';

# Review: 0003 is CREATE TABLE, one nullable ADD COLUMN, three constraints; 0004 is two defaulted NOT NULL ADD COLUMNs plus a data backfill from journey. Both are additive and safe against the previously deployed code (the CLAUDE.md requirement): an older build inserts versions without title/description and gets the default. If the Vercel build wins its race with the Migrate action there is a brief window of errors on the pages that read the new columns; that window is inherent to the deploy model, not to these migrations.
